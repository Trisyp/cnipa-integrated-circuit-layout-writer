# 简要说明（布图登记）

## 写什么
- 该布图的**结构、技术、功能**等概述，便于审查员理解图样所表达的电路配置。
- 可设「图样说明」，将文字与图样页码对应。
- 使用层表/术语表中的正式名称；与目录、图页、独创性声明一致。

## 不写什么
- 不要写成发明专利「权利要求书」或「具体实施方式」长篇堆砌。
- 不要粘贴未公开坐标表、完整网表、可复原的掩膜数据。
- 不要用「本发明权利要求保护……」口吻；布图登记叙事是独创布图表达。
- 不要保证「一定能登记成功」。
- 不要把算法复杂度、数学最优当作布图独创性的替代论证。
- 不要代填或编造创作人、创作完成日、权属、商业利用、样品、签章等法定事实。修订日/构建日 ≠ 创作完成日。
- 不要在无签核证据时写已完成第三方 PDK DRC/LVS/流片。

## 与独创性声明的分工
- 简要说明：结构、技术、功能及图样页对应说明。
- 独创性声明（修订条例下的法定提交文件，通常单独一类一包）：独创性设计区域、设计要点及相应功能。
- 两者层名、页码应同源；声明中的签章/日期/申请人栏留空待申请人。

## 图样表述
- 原创分层图样或从真实源导出的图样：称「本布图设计之图样/层」，不必强制加「仅规划示意/非正式掩膜」。
- 仅当图样确为中心线/示意占位页时，才在显著位置声明其为规划/示意，并不得称为已签核掩膜。

## 可选公式
- 若功能说明需要公式，可用 OMML（见 omml-equations.md），且符号可追溯；无公式亦可。

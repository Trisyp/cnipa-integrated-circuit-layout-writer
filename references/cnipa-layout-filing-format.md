# 集成电路布图设计登记 — 电子申请材料格式摘要

> 下列条目据 CNIPA 布图设计**电子申请帮助页**核对摘要整理，供本 skill 门禁与打包脚本对齐。  
> **勿声称已核对全部法规/审查指南全文。** 递交前以 http://vlsi.cnipa.gov.cn 当前帮助页与官方最新要求为准。

## 1. 材料类别（概念）

常见类别（项目可增减，但「一类一包」）：

| 类别 | 典型内容 |
|------|----------|
| 登记申请表 | 电子表单字段（本 skill 只维护「待填项清单」，不代替官网填表） |
| 设计图样 | 总图 + 分层图，TIFF/TIF |
| 图样目录 | 每页图层名称 |
| 简要说明 | 结构 / 技术 / 功能等 |
| 委托书等 | 若有，单独一类 |

## 2. ZIP 打包规则（门禁对齐）

1. **除登记申请表外**，其他文件按类别分别打成 ZIP。
2. **ZIP 内不得有文件夹**（全部文件在包根目录）。
3. 包内图样文件连续命名：`1.tiff`、`2.tiff`、…（允许 `.tif`，但同一包内扩展名应统一；编号从 1 起连续无跳号）。
4. **单包 ≤ 150MB**。
5. 图样、图样目录、委托书、简要说明等 **各自一类一包**（不要把说明和 TIFF 打进同一个业务 ZIP，除非官方当前帮助页明确允许——默认按一类一包）。

## 3. 图样与目录

- 图样含**总图**与**分层图**。
- 纸件习惯：A4，**每页一幅**，顺序编号。
- **图样目录**写明**每页图层名称**（与 TIFF 序号一一对应）。
- 页码/页序须与申请表所填一致。

## 4. 保密信息

- 若符合「未商业利用」等条件，可保留保密信息；公开帮助页口径：**不超过总面积 50%**（具体资格以官方为准）。
- 声称保密的区域须在公开图样上不可辨认；简要说明勿泄露拟保密几何细节。
- 门禁：`SECRET_CLAIM_LEAK`（见 SKILL.md）。

## 5. 规划 / 示意 vs 正式掩膜

格式规则不区分「规划」与「正式」，但本 skill **内容纪律**要求：

- 无真实 GDS/OASIS/层映射 → 全部图样与目录标注「规划/示意」；
- 不得在简要说明或文件名中声称「正式掩膜」「流片版图」等。

## 6. 站点

- 电子申请：http://vlsi.cnipa.gov.cn

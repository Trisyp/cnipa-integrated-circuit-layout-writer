# 集成电路布图设计登记 — 电子申请材料格式摘要

## 来源层级（递交前再对官网）

| 层级 | 来源 | 用法 | 核验状态 |
|------|------|------|----------|
| A | CNIPA / vlsi 电子申请帮助页公开的硬规格（一类一包、ZIP 无文件夹、连续 `1.tiff`、单包 ≤150M 等） | **判断能否按电子申请提交的格式标准** | 公开页摘要已核 |
| B | 《集成电路布图设计保护条例》（2026 年修订，约 2026-10-15 施行）及新细则之**公开说明** | **判断法定文件种类与独创性声明等实体要求** | 摘要已核；**细则全文 PDF 仍可能待核**，递交前再对官网 |
| C | 参考示例文件夹（可提交样本） | **只学习打包方式**（一类一包、ZIP 无文件夹、连续 `1.tiff`） | **不是规格上限**；不必逐像素/逐页/逐分辨率/凑页数对齐；禁止抄示例工艺几何 |

> **勿声称已核对全部法规/审查指南/细则全文。** 递交前以 http://vlsi.cnipa.gov.cn 当前帮助页与官方最新文本为准。
> 本 skill **不保证登记获准**。

## 1. 材料类别（概念）

常见类别（项目可增减，但「一类一包」）。**默认四分包** + 在线申请表；委托书等视情况另包：

| 类别 | 典型内容 | 本 skill 职责 |
|------|----------|----------------|
| 登记申请表 | 电子表单字段 | 只维护「待填项清单」，**不代替官网填表**，不代填法定事实 |
| 设计图样 | 总图 + 分层图，TIFF/TIF | 按图样来源分层生成或导出，打包 |
| 图样目录 | 每页图层名称 | 与 TIFF 序号一一对应 |
| 简要说明 | 结构 / 技术 / 功能等；可有「图样说明」对应页码 | 起草技术正文，不编造法定事实 |
| 独创性声明 | 独创性设计区域、设计要点及相应功能 | 起草技术正文；**签章/日期/申请人等栏留空**；单独一类一包 |
| 委托书等 | 若有，单独一类 | 按需打包，不代签 |

## 2. ZIP 打包规则（门禁对齐，层级 A）

1. **除登记申请表外**，其他文件按类别分别打成 ZIP。
2. **ZIP 内不得有文件夹**（全部文件在包根目录）。
3. 包内图样文件连续命名：`1.tiff`、`2.tiff`、…（允许 `.tif`，但同一包内扩展名应统一；编号从 1 起连续无跳号）。
4. **单包 ≤ 150MB**。
5. 图样、图样目录、简要说明、独创性声明、委托书等 **各自一类一包**（不要把说明和 TIFF 打进同一个业务 ZIP，除非官方当前帮助页明确允许——默认按一类一包）。

## 3. 图样与目录

- 图样含**总图**与**分层图**。
- 纸件习惯：A4，**每页一幅**，顺序编号。
- **图样目录**写清**每页图层名称**（与 TIFF 序号一一对应）。
- 页码/页序须与申请表所填一致。
- 分辨率、页数、色彩模式以满足官方可接受规格与本设计表达需要为准，**不必**与参考示例一致。

## 4. 简要说明

- 写该布图的**结构、技术、功能**等。
- 可设「图样说明」，将说明文字与图样页码对应。
- 使用层表中的正式层名/模块名，与目录、图页一致。

## 5. 独创性声明（2026 年修订要点，层级 B）

修订条例公开说明下，**独创性声明是法定提交文件**，应指明：

1. 独创性设计区域；
2. 设计要点；
3. 相应功能。

电子申请通常需将其做成**单独一类一包** TIFF ZIP（无文件夹、`1.tiff` 连续、≤150M）。

- 技术正文可由本 skill 起草，并与图样页/层名对应。
- **签章、日期、申请人、创作人等法定事实不得编造**，栏位留空待申请人填写。
- 独创性对象仍是可辨认的三维配置/拓扑表达；禁止把算法最优、数学下界或性能数字直接写成法律独创性。
- 上述为公开说明摘要；细则全文 PDF 仍可能待核，具体栏目与格式以递交当时官网为准。

## 6. 参考示例的定位（层级 C）

参考示例只是一套**可提交样本**，供学习：

- 一类一包；
- ZIP 内无文件夹；
- 连续 `1.tiff`、`2.tiff`… 命名。

它**不是**规格上限，也不是本设计必须对齐的页数、分辨率、色彩或分层表达模板。禁止描摹或搬用示例中的工艺层几何。

## 7. 图样来源分层（内容纪律，非格式规格本身）

格式规则不强制写「规划」或「正式」字样，但本 skill **内容纪律**要求：

- **有 foundry/真实 GDS/OASIS + 层映射**：从源图按非空层导出正式图样。
- **无外部 GDS，但项目有可复现的布线/模块几何**：生成「本布图设计之原创分层图样」（金属用真实线宽多边形，过孔用阵列；总图 + 分层齐全、目录对应）。文案用「本布图设计之图样/层」，**不要强制再标「仅规划示意/非正式掩膜」**。
- **仍然禁止**在无签核证据时声称已完成第三方 PDK DRC/LVS/流片签核；禁止把中心线示意图直接当已签核掩膜。
- 仅有中心线/示意几何时，才使用规划示意页并标明「规划/示意」。
- 门禁：无签核证据的 DRC/LVS/流片声明 → `PLAN_AS_MASK` FAIL；未导入 foundry GDS 的原创图样未写「规划」二字 → **不再 FAIL**。Foundry 源图本身不等于签核证据。

## 8. 保密信息

- 若符合「未商业利用」等条件，可保留保密信息；公开帮助页口径：**不超过总面积 50%**（具体资格以官方为准）。
- 声称保密的区域须在公开图样上不可辨认；简要说明与独创性声明勿泄露拟保密几何细节。
- 门禁：`SECRET_CLAIM_LEAK`（见 SKILL.md）。
- 「是否商业利用」「是否提交样品」属法定事实，本 skill **不代填**。

## 9. 法定事实（本 skill 不代填）

以下栏位由申请人确认，skill 只列待填项，不得编造：

- 创作人
- 创作完成日（**修订日 / 构建日 / 交付日均不等于创作完成日**）
- 权属
- 是否商业利用
- 样品及相关声明
- 申请人签章与日期

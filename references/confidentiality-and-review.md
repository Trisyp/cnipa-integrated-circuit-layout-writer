# 保密、公网检索与本地回填（布图登记）

适用于集成电路布图设计登记项目。示例均为通用占位，**不含任何真实项目的层几何、参数或未公开方案**。

## 一、红线
- **严禁**把未公开布图（GDS/OASIS/TIFF 正式页）、层映射细节、核心参数、未公开技术方案输入公网或消费级 AI。**输入可能视为公开。**
- 聊天/日志只报结构结论与 PASS/FAIL，不贴图样可复原描述或坐标。
- 本地优先：导出、打包、门禁、渲染均在用户本机项目目录。

## 二、流程：脱敏 → 公开对照 → 本地回填
1. 公网检索只用隐去几何与核心参数的框架词（如「基带加速单元 布图登记 分层图样 格式」这类流程词，而非本设计坐标）。
2. 先跑 `scripts/query_guard.py` 再粘贴检索式。
3. 公开资料用于了解登记格式与通用工艺常识；**不得**把他人布图几何当本作内容。
4. 不编造「已登记号」「对比面积百分比」等假数据。
5. 本地回填真实层名与正式图样；规划标记在正式源就绪后删除。

## 三、独创性表述纪律
- 独创性对象：布图三维配置/拓扑的可辨认表达。
- 禁止：从算法最优、信息论下界、仿真增益直接断言「具备登记独创性」或「必然获准」。
- 内部创新性备忘可写工程差异；对外简要说明保持登记文书语气。

## 四、深度复盘清单（节选）
- [ ] 是否仍处于规划模式？四处标记一致？
- [ ] 目录 ↔ TIFF ↔ 简要说明层名一致？
- [ ] ZIP 一类一包、无文件夹、连续编号、≤150M？
- [ ] 保密面积与遮盖是否与申请表页码一致？
- [ ] 交付哈希清单是否与当前文件一致？
- [ ] 参考示例几何是否被误复制？（抽查）

# 简要说明 docx 版式（可选）

布图登记主交付是 TIFF + 目录 + 简要说明；简要说明可用 `.docx` 或纯文本。若用 docx：

- 纸张 A4；正文宋体小四左右；标题黑体。
- 不要套用发明专利「四节页眉」（说明书摘要/权利要求书/…）——那是专利结构。
- 页眉可用「简要说明」或项目约定；页码与申请表一致。
- 只借用户提供的**说明类**模板版式；不抄其技术段落。
- 视觉校验可沿用 `scripts/render_check.py`（docx→pdf→png）。

原发明专利精确四节参数已不适用；专利版式详见上游 `cnipa-patent-writer` 仓库，不在本 skill 主路径维护。

# 设计图样（TIFF）与规划页

## 硬规则
1. **只借参考示例的版式**（纸张、页边、编号、图框习惯），**不描其多边形/布线**。
2. A4，每页一幅；总图 + 分层图齐全（层集由用户层表决定，不照搬示例层数）。
3. 电子包内命名：`1.tiff`…`N.tiff` 连续。
4. **无真实掩膜源** → 每页可见「规划/示意」字样；目录同行标注；禁止伪称正式掩膜。
5. 层名与目录、简要说明同源；改名全链同步。
6. 保密区按官方面积口径处理；遮盖后不可辨认关键几何。
7. 虚构夹具与 selftest 只用几何无关的示意矩形/网格，避免像任何真实工艺。

## 推荐生成
- 正式：从 GDS/OASIS + 层映射导出（项目自备工具链）；本 skill 不内置未授权的 Foundry 流程。
- 规划：`scripts/make_planning_tiffs.py` 生成带水印的示意 TIFF（纯虚构）。

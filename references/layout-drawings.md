# 设计图样（TIFF）与来源分层

## 硬规则
1. **参考示例只学打包与常见版式习惯**（一类一包、无文件夹、连续编号、纸张/页边等），**不是**页数、分辨率或色彩上限，**不描其多边形/布线**。
2. A4，每页一幅；总图 + 分层图齐全（层集由用户层表决定，不照搬示例层数）。
3. 电子包内命名：`1.tiff`…`N.tiff` 连续。
4. 文案默认用「本布图设计之图样/层」。按来源分层处理，不要把中心线示意图直接当已签核掩膜。
5. 层名与目录、简要说明、独创性声明同源；改名全链同步。
6. 保密区按官方面积口径处理；遮盖后不可辨认关键几何。
7. 虚构夹具与 selftest 只用几何无关的示意矩形/网格，避免像任何真实工艺。
8. **禁止**在无签核证据时声称已完成第三方 PDK DRC/LVS/流片签核。

## 图样来源分层
- **有 foundry/真实 GDS/OASIS + 层映射**：从源图按非空层导出正式图样。本 skill 不内置未授权的 Foundry 流程；导出工具链由项目自备。接入真实源图也不等于已获得 PDK 签核。
- **无外部 GDS，但项目有可复现的布线/模块几何**：应生成「本布图设计之原创分层图样」。金属用真实线宽多边形，过孔用阵列；总图 + 分层齐全，目录与页面对应。**不要强制再标「仅规划示意/非正式掩膜」**。未写「规划」二字不应被门禁判 FAIL。
- **仅有中心线/示意几何、无可复现线宽与过孔阵列**：使用规划示意页，页内与目录均标注「规划/示意」。可用 `scripts/make_planning_tiffs.py` 生成带水印的虚构示意 TIFF。禁止将此类页说成已签核掩膜。

## 推荐生成
- 真实源：项目自备 GDS/OASIS + 层映射导出（A4、每页一幅 TIFF）。
- 可复现几何：按层表渲染真实线宽金属多边形与过孔阵列，输出总图与分层页。
- 示意占位：`scripts/make_planning_tiffs.py`（纯虚构，非正式签核掩膜）。

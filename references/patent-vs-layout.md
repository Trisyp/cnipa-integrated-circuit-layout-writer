# 发明专利 skill vs 集成电路布图登记 skill

| 项 | cnipa-patent-writer | cnipa-integrated-circuit-layout-writer |
|----|---------------------|----------------------------------------|
| 目标 | 发明专利申请 .docx | 布图设计登记材料包 |
| 主文件 | 摘要、权利要求书、说明书、附图 | 简要说明、设计图样 TIFF、图样目录、独创性声明（默认四分包） |
| 图 | PNG 嵌入说明书附图节 | 分层 TIFF + 一类一包 ZIP |
| 核心法律叙事 | 新颖性/创造性/权利要求 | 布图独创表达（三维配置/拓扑）；禁止数学最优 → 法律独创性 |
| 判断标准 | 专利审查与文件格式习惯 | CNIPA/vlsi 电子申请硬规格 + 2026 年修订条例及新细则公开说明；参考示例只学打包方式，非上限 |
| 禁止 | 背景写本发明、权1堆小数等 | 无签核证据声称 DRC/LVS/流片、把中心线示意图当已签核掩膜、抄参考几何、ZIP 违规、编造法定事实 |
| 法定事实 | 按专利请求书规则 | 创作人、创作完成日、权属、商业利用、样品等不代填；修订日/构建日 ≠ 创作完成日 |
| 申请表 | 请求书等书面文件 | vlsi 在线填写；skill 只维护待填项清单 |
| 主脚本 | build_patent*.py | pack_layout_zips.py / check_layout_package.py / layout_gates.py；make_planning_tiffs.py 仅用于示意占位页 |
| 废弃 | — | scripts/deprecated/ 下原专利装配器 |

公式与 docx 工具可继续用于**简要说明**，但不再维护「权利要求三处同源」主线。
独创性声明技术正文可起草，签章/日期/申请人栏留空。本 skill 不保证登记获准。
